## Tutorial payoff and humour audit

### `quickstart.md` payoff matrix

| Step | Action                                 | Immediate payoff                                                                                                |
| ---- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 1    | Start and inspect the offline service. | A running service exists at the chosen throwaway state path; no provider is contacted.                          |
| 2    | Create and attach to the session.      | The terminal is attached to the durable session owned by that service.                                          |
| 3    | Send a short instruction.              | The pinned offline worker completes a managed turn with no paid provider request.                               |
| 4    | Probe, inspect and stop.               | Startup, session durability, attachment, a managed turn, inspection and clean shutdown have all been exercised. |

The one running gag is the deliberately tiny first assignment:

1. introduction: the agent must “say hello without calling anyone”;
2. step 3 payoff: “There is our hello” and the zero bill;
3. step 4 payoff: the “tiny hello” finishes its shift;
4. closing payoff: the “very undemanding first assignment” disappears with throwaway state.

These are repetitions of one motif, not separate jokes. No humour appears inside a command, literal value, output, JSON block, table, warning, failure diagnosis or recovery instruction.
