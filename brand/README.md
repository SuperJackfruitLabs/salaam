# Salaam brand assets

`mark.svg` is the unmodified Salaam Nod color master from
`sjl-marketing/brand/product-logos/translucent-v2/products/salaam/svg/mark-color.svg`,
asset handoff dated 14 October 2026. The suite manifest marks the Salaam Nod as
**provisional, pending design iteration**. This implementation follows that existing
asset family; it does not assert new brand approval.

The same master supplies the landing/docs header. Adaptive favicon and Apple icon
copies come from that product's `web/` directory. The sites' jade accents and
Night/Paper surfaces preserve Salaam's implemented TUI palette.
